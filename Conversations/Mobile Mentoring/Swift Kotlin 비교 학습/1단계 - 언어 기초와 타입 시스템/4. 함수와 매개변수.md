## 오늘의 학습 목표

- Swift 함수의 외부 매개변수 이름과 내부 이름이 호출 문장을 어떻게 설명하는지 구분한다.
- Kotlin의 기본 매개변수와 named argument를 읽고, 호출 순서를 바꿀 수 있는 조건을 설명한다.
- 화면 표시용 값처럼 계산 결과가 필요한 경우 `Void`/`Unit` 대신 반환값을 선택하는 이유를 말한다.

## 1. 개념 읽기

### Swift에서 알아둘 점

- Swift 함수는 `func 이름(매개변수: 타입) -> 반환타입` 형태로 선언한다. 반환값이 없으면 `-> Void`를 생략할 수 있다.
- 기본적으로 함수 호출에서는 매개변수 이름을 함께 쓴다. `format(steps: 3200)`처럼 호출 문장만 보아도 값의 역할을 읽기 쉬운 이유다.
- 외부 이름과 함수 내부에서 쓰는 이름은 다르게 둘 수 있다. `func move(from start: Int, to end: Int)`는 호출할 때 `move(from: 1, to: 3)`처럼 문장으로 읽히고, 본문에서는 `start`, `end`를 쓴다.
- 외부 이름을 `_`로 두면 `sum(3, 4)`처럼 이름 없이 호출한다. 자주 쓰는 수학적 연산처럼 이름이 오히려 방해될 때에만 선택하는 편이 좋다.

```swift
func progressText(steps: Int, goal: Int = 8_000) -> String {
    let percent = Int(Double(steps) / Double(goal) * 100)
    return "\(percent)%"
}

let label = progressText(steps: 4_000)          // "50%"
let customLabel = progressText(steps: 4_000, goal: 5_000) // "80%"
```

### Kotlin에서 알아둘 점

- Kotlin 함수는 `fun 이름(매개변수: 타입): 반환타입` 형태다. 반환값이 없으면 `Unit`을 생략할 수 있다.
- 기본값은 `fun progressText(steps: Int, goal: Int = 8_000): String`처럼 선언한다. 호출에서 기본값을 쓰면 해당 인수는 생략할 수 있다.
- Kotlin은 호출할 때 `progressText(steps = 4_000)`처럼 named argument를 쓸 수 있다. named argument를 쓴 뒤의 인수는 이름을 붙여야 하므로, 여러 선택 매개변수의 의미와 순서를 분명하게 만들 때 유용하다.
- `return`은 명시적으로 쓸 수 있고, 한 식으로 끝나는 함수는 `=`를 써서 반환식을 간단히 표현할 수도 있다.

```kotlin
fun progressText(steps: Int, goal: Int = 8_000): String {
    val percent = (steps.toDouble() / goal * 100).toInt()
    return "$percent%"
}

val label = progressText(steps = 4_000)              // "50%"
val customLabel = progressText(goal = 5_000, steps = 4_000) // "80%"
```

### 두 언어의 핵심 차이

- Swift의 호출 레이블은 함수 선언의 일부다. Kotlin의 named argument는 호출자가 선택해 붙이는 이름이지만, 기본 호출은 위치 기반이다.
- 두 언어 모두 기본 매개변수로 호출 수를 줄일 수 있다. 다만 API를 여러 모듈에 공개할 때는 기본값 변경이 호출 결과에 영향을 줄 수 있으므로, 값의 의미와 버전 호환성을 함께 검토한다.
- 계산한 결과를 화면·ViewModel·다음 로직에서 사용해야 하면 `String`, `Int`, 모델 같은 반환값을 쓴다. 로그를 남기거나 상태를 바꾸는 것만이 목적이면 `Void`/`Unit` 함수가 자연스럽다.

## 2. 개념 선택

> 단일 선택: 함수와 매개변수에 대한 설명 중 가장 정확한 것을 하나 고른다.

- [ ] A. Swift 함수는 모든 호출에서 매개변수 이름을 생략해야 한다.
- [ ] B. Kotlin의 기본 매개변수는 호출할 때도 반드시 값을 넘겨야 한다.
- [ ] C. 반환값은 함수 내부에서만 쓸 수 있어 호출한 쪽에는 전달되지 않는다.
- [x] D. 두 언어 모두 기본 매개변수로 자주 쓰는 값을 선언해 일부 호출에서 인수를 생략할 수 있다.

> [!answer]- 정답과 해설 확인
> - 정답: D
> - 해설: Swift와 Kotlin 모두 선언에서 기본값을 정할 수 있고, 호출자가 그 값을 그대로 쓸 때 해당 인수를 생략할 수 있다. Swift는 기본적으로 호출 레이블을 사용하며, Kotlin은 기본 호출이 위치 기반이지만 named argument를 선택할 수 있다.


## 3. Swift 코드 읽기

> 단일 선택: 다음 코드의 출력으로 맞는 것을 고른다.

```swift
func greeting(for name: String, punctuation: String = "!") -> String {
    "안녕하세요, \(name)\(punctuation)"
}

print(greeting(for: "Zero"))
```

- [x] A. `안녕하세요, Zero!`
- [ ] B. `안녕하세요, Zero`
- [ ] C. `greeting(for:)`는 반환값이 없어 컴파일 오류
- [ ] D. `punctuation` 인수를 생략해서 컴파일 오류

> [!answer]- 정답과 해설 확인
> - 정답: A
> - 해설: `punctuation`에는 기본값 `"!"`가 있으므로 생략할 수 있다. Swift 선언의 외부 이름 `for`를 사용해 호출하고, 함수가 만든 `String`을 `print`가 출력한다.


## 4. Kotlin 코드 읽기

> 단일 선택: 다음 코드의 출력으로 맞는 것을 고른다.

```kotlin
fun displayName(name: String, prefix: String = "회원"): String {
    return "$prefix: $name"
}

println(displayName(name = "Zero"))
```

- [ ] A. `Zero`
- [x] B. `회원: Zero`
- [ ] C. `prefix`를 생략해서 컴파일 오류
- [ ] D. named argument는 기본 매개변수와 함께 쓸 수 없다.

> [!answer]- 정답과 해설 확인
> - 정답: B
> - 해설: `name = "Zero"`은 named argument이고, 생략한 `prefix`에는 기본값 `"회원"`이 적용된다. 함수의 반환 문자열은 `회원: Zero`다.


## 5. 올바른 코드 선택

> 단일 선택: 걸음 수와 목표 수로 달성률 문자열을 만들어 호출한 곳에서 사용할 수 있는 Swift 코드 하나를 고른다.

### A

```swift
func progressText(steps: Int, goal: Int) {
    "\(steps / goal)%"
}
```

- [ ] A 선택

### B

```swift
func progressText(steps: Int, goal: Int) -> String {
    let percent = Int(Double(steps) / Double(goal) * 100)
    return "\(percent)%"
}
```

- [x] B 선택

### C

```swift
func progressText(steps: Int, goal: Int) -> String {
    print("\(steps / goal)%")
}
```

- [ ] C 선택

### D

```swift
func progressText(steps: Int, goal: Int) -> String {
    return steps / goal
}
```

- [ ] D 선택

> [!answer]- 정답과 해설 확인
> - 정답: B
> - 해설: B는 소수 비율을 계산한 뒤 `String`으로 반환하므로 호출한 화면이나 상태 모델이 결과를 재사용할 수 있다. A는 반환 타입이 없어 만든 문자열을 버리고, C는 `String`을 반환하겠다고 선언했지만 `print`의 결과는 `Void`이며, D는 `Int`를 `String`으로 반환하려 한다.


## 6. Swift · Kotlin 차이 선택

> 복수 선택 가능: 두 언어의 함수 호출 차이를 올바르게 설명한 보기를 모두 고른다.

- [x] A. Swift에서 `func move(from start: Int, to end: Int)`는 보통 `move(from: 1, to: 3)`처럼 외부 레이블을 써서 호출한다.
- [x] B. Kotlin은 `move(end = 3, start = 1)`처럼 named argument를 쓰면 선언 순서와 다른 순서로 인수를 전달할 수 있다.
- [ ] C. Kotlin에서 named argument를 하나 쓴 뒤에는 그 뒤에 위치 인수를 그대로 이어 써도 된다.
- [x] D. Swift와 Kotlin 모두 기본 매개변수는 호출 문장을 줄일 수 있지만, 기본값의 의미를 문서화할 필요가 있다.

> [!answer]- 정답과 해설 확인
> - 정답: A, B, D
> - 해설: Swift의 외부 매개변수 이름은 호출 문장의 일부다. Kotlin은 named argument를 이용해 이름과 함께 인수를 전달할 수 있고, 그 경우 선언 순서와 다른 순서도 가능하다. Kotlin에서는 named argument 뒤에 위치 인수를 이어 쓰지 않는다.
