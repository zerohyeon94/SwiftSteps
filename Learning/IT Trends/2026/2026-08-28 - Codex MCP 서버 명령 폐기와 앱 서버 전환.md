# 2026-08-28 - Codex MCP 서버 명령 폐기와 앱 서버 전환

> Daily: [[2026-08-28]]
> 분류: IT Trends
> 영역: IDE·ADE·AI 코딩 도구
> 읽기 목표: 5-10분

## 한 줄 요약

OpenAI는 2026년 8월 24일 `codex mcp-server` 명령을 폐기(deprecated)하고 Codex 앱 서버를 사용하도록 안내했다. 이는 MCP 자체가 사라진다는 뜻이 아니라, Codex를 다른 도구와 연결할 때의 진입점이 바뀐다는 공지다.

## 왜 지금 볼 만한가

AI 코딩 도구의 가치는 모델 하나보다 에디터·CLI·브라우저·MCP 도구와 어떤 프로세스로 연결되는지에 크게 좌우된다. 로컬 자동화나 팀 도구가 특정 CLI 하위 명령에 묶여 있다면, 명령 하나의 폐기도 실행 경로·인증·설정 문서를 함께 점검해야 하는 변화가 된다.

이번 공지는 기능을 새로 추가했다기보다 **연결 경로의 소유 경계**를 정리한다. 개발자는 “MCP를 쓴다”는 넓은 표현 대신, 어떤 앱 또는 서버가 연결을 제공하고 클라이언트가 어디로 붙는지를 문서화할 필요가 있다.

## 핵심 내용

### 바뀐 것은 명령의 권장 경로다

공식 릴리스 노트는 `codex mcp-server` 명령이 더 이상 권장되지 않으며 Codex 앱 서버를 사용하라고 안내한다. Claude Code에서 Codex를 사용할 경우에는 Codex 플러그인을 사용하라는 별도 경로도 제시한다.

따라서 기존 스크립트·온보딩 문서에 해당 명령이 있다면, 첫 작업은 “명령 문자열을 바꾸기”보다 그 명령이 맡았던 역할을 확인하는 것이다. 예를 들어 도구 목록을 노출했는지, 로컬 앱 세션과 붙었는지, 별도 프로세스를 띄웠는지에 따라 대체 확인 항목이 달라진다.

![[Assets/2026-08-28 - Codex 앱 서버 전환 - 연결 경로.svg]]

> 그림은 공식 공지의 권장 연결 경로만 비교한 개념도다. 조직별 인증 방식·권한·네트워크 설정은 공지 하나로 확정되지 않으므로 실제 전환 전 현재 Codex 문서를 다시 확인해야 한다.

### MCP라는 표준과 Codex의 실행 진입점을 구분한다

MCP(Model Context Protocol)는 도구·리소스 같은 컨텍스트를 클라이언트에 연결하기 위한 프로토콜 계열을 가리킨다. 반면 `codex mcp-server`와 Codex 앱 서버는 Codex 제품에서 그 연결을 제공하거나 시작하는 구체적 방식이다.

그래서 다음 두 문장은 같지 않다.

- “MCP 도구를 더 이상 쓸 수 없다.” — 이번 공지만으로는 뒷받침되지 않는다.
- “기존 `codex mcp-server` 명령에 의존하던 설정은 권장 진입점을 다시 확인해야 한다.” — 공식 공지와 일치한다.

### 전환 점검 순서

1. 저장소의 셸 스크립트·README·CI 설정에서 `codex mcp-server` 문자열을 찾는다.
2. 각 위치가 개발자 로컬용인지, 팀 공용 가이드인지, 자동화 실행 경로인지 분류한다.
3. Codex 앱 서버 또는 해당 통합의 공식 문서에서 지원 명령·인증·권한 범위를 확인한다.
4. 실제로 연결되는 도구 목록과 권한 요청을 최소 테스트로 확인한다.
5. 이전 명령을 제거하기 전, 팀원이 되돌릴 수 있도록 변경 이유와 기준 버전을 기록한다.

## 개발자가 알아둘 변화

- **명령이 아니라 연결 책임을 기록한다.** “MCP 서버 실행”만 적지 말고 누가 서버를 띄우고 어떤 클라이언트가 접속하는지 남긴다.
- **통합별 경로를 섞지 않는다.** Codex 앱, CLI, 다른 코딩 도구의 플러그인은 같은 목적을 가질 수 있어도 설치·인증·권한 경로가 다를 수 있다.
- **폐기와 즉시 삭제를 구분한다.** deprecated는 새 사용을 권장하지 않는 기능 상태지만, 실제 제거 시점과 호환성은 공식 문서·릴리스 노트를 확인해야 한다.
- **MCP 도구 권한은 별도 점검한다.** 앱 서버 전환이 파일·네트워크·외부 서비스 권한을 자동으로 줄이거나 늘린다고 가정하지 않는다.

## 용어와 맥락

- **deprecated(폐기 예정)**: 새 사용을 권장하지 않는 기능 상태다. 즉시 작동 불능과 같은 뜻은 아니다.
- **앱 서버(app server)**: Codex 제품이 외부 클라이언트·통합과 연결될 때 사용하는 권장 서버 진입점이다.
- **클라이언트**: MCP 도구나 리소스를 요청하는 에디터·앱·에이전트다.
- **권한 경계**: 어떤 프로세스가 파일·네트워크·연결된 서비스에 접근할 수 있는지 정하는 범위다.
