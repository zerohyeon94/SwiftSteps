## 🔬 오늘의 IT 동향

- **Apple Intelligence + Core ML**: iOS 18에서 `FoundationModels` 프레임워크 공개 — 앱 내에서 온디바이스 LLM 직접 호출 가능. ZipJoong의 집중 리포트 기능에 연동 가능성 있음.
- **FastAPI + uv**: Python 패키지 관리 도구로 `uv`가 빠르게 표준화 중. MyHealthBuddy가 이미 uv를 쓰고 있어 CI도 uv 기준으로 맞춰야 함.
- **헬스케어 AI 규제**: FDA가 AI/ML 기반 의료기기 소프트웨어(SaMD) 가이드라인 업데이트 중 — 의료기기 인허가 경험이 있는 개발자에게 유리한 흐름.
