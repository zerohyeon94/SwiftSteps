### 💬 기술 피드백

- 학습 메모·실습/프로젝트 메모·오늘 하루 정리·개념 연결에 직접 작성한 기록이 없어, 함수의 호출 레이블·기본값·반환값을 어떤 기준으로 구분했는지와 선택 문제의 오답 원인은 확인할 수 없습니다.
- 완료로 표시한 IT 동향에서는 Android의 적응형 UI를 ‘화면 크기를 입력값으로 받는 상태 설계’로 연결해 둔 점이 좋습니다. 다만 읽기 완료 표시만으로는 큰 화면 전환에서 어떤 상태를 보존해야 하는지까지 확인할 수 없으므로, 다음에 읽을 때는 화면 크기 변화에도 유지되어야 할 상태 한 가지를 학습 메모에 적어 보세요.
- Day 4를 재개할 때는 Swift의 argument label과 Kotlin의 named argument가 호출부에서 각각 무엇을 드러내는지 먼저 비교하고, 기본값이 있을 때 호출자가 생략해도 되는 인수를 구분해 보세요. 반환값은 호출 뒤에 활용할 새 값을 전달할 때 쓰고, 부수 효과만 수행하는 함수와 구분하는 기준을 한 문장으로 남기면 이해 여부를 검토할 수 있습니다.

### 🔗 오늘 개념 연결

- 함수의 인수 이름은 호출 의도를 드러내는 API 설계 요소입니다. Android의 적응형 UI도 창 크기·방향·화면 상태처럼 변경 가능한 입력을 명확히 모델링해야 하므로, 둘 다 ‘호출자와 상태 변화의 의미를 이름으로 드러낸다’는 관점으로 연결할 수 있습니다.
