### 💬 기술 피드백

기본값을 생략한 호출의 결과와 `String` 반환 함수를 정확히 구분한 점은 좋다. 특히 `progressText`를 단순 출력 함수가 아니라 호출자가 재사용할 값을 돌려주는 함수로 고른 것은 화면·ViewModel 경계에서 필요한 판단이다.

직접 작성 메모가 없으므로, Swift의 외부 매개변수 이름이 **선언된 API의 호출 문장 일부**라는 점과 Kotlin의 named argument가 **호출 시 선택하는 표기**라는 차이를 실제로 설명할 수 있는지는 확인할 근거가 없다. 다시 시작할 때 `move(from:to:)`와 `move(end = ..., start = ...)`를 각각 한 문장으로 비교하고, 기본값이 바뀔 때 기존 호출의 의미가 달라질 수 있다는 점을 함께 적어 보자.

### 🔗 오늘 개념 연결

- 외부 레이블·named argument는 호출 지점에서 값의 역할을 드러내는 API 설계 도구다.
- 기본 매개변수는 반복 호출을 줄이지만, 공개 API에서는 기본값 자체가 동작 계약이 된다.
- 반환값은 표시 문자열이나 계산 결과를 UI·상태 모델에서 다시 사용할 수 있게 하므로, 부수 효과만 수행하는 `Void`/`Unit` 함수와 구분한다.
