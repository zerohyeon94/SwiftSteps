## 🌙 오늘 하루 피드백 (2026-08-06)

### ✅ 완료한 것

- Swift Optional과 Kotlin nullable type 비교 워크북을 완료로 표시했습니다.
- Android 16의 적응형 UI 전환, 물가와 실질수익률, 상관관계와 인과관계 읽기를 각각 완료로 표시했습니다.

### 💬 기술 피드백

완료 체크는 핵심 학습과 일일 루틴을 모두 통과했음을 보여 줍니다. 특히 Optional/nullable 처리와 Android의 창 크기 기반 UI는 모바일 네이티브 확장이라는 현재 목표에 직접 연결되는 조합입니다. 다만 학습 메모와 실습/프로젝트 메모가 비어 있어, `nil`/`null`을 안전하게 처리할 실제 앱 경계(API 응답·UI 상태 등)와 넓은 화면에서 보존할 UI 상태를 어떻게 이해했는지는 확인할 수 없습니다. 다음 학습 뒤에는 핵심 개념 한 문장과 헷갈린 지점 한 문장만 남겨도 다음 복습의 근거가 생깁니다.

물가와 실질수익률은 명목수익률과 같은 기간 기준으로 비교해야 하며, 상관관계는 원인·결과를 곧바로 뜻하지 않는다는 점이 핵심입니다. 두 읽기를 함께 볼 때는 수치의 관계와 인과 해석을 분리하는 습관을 유지하세요.

### 🔗 오늘 개념 연결

- Optional/nullable type은 서버 응답이나 화면 상태처럼 값이 없을 수 있는 데이터를 타입으로 표현하고, 적응형 UI는 같은 상태를 서로 다른 창 크기에서 안전하게 보여 주는 문제입니다.
- 실질수익률과 상관관계·인과관계 모두 숫자를 읽을 때 기준 기간·비교 조건·해석 범위를 먼저 고정해야 한다는 공통점을 가집니다.
